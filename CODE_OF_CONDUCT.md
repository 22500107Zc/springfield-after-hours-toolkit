# Code of conduct

## The short version

Be decent. This is a volunteer fan project about a twenty-year-old licensed
video game. Nothing here is worth being unpleasant to another person over.

## Expected behaviour

- Assume good faith. Someone who got a game fact wrong made a mistake; they did
  not commit a moral failing.
- Be patient with newcomers. Mod development has a steep learning curve and this
  toolkit deliberately refuses to do things, which is confusing until explained.
- Give credit. If someone verified a locator, the registry record should say so.
- Accept correction gracefully. This project's core premise is that unverified
  claims get challenged. That applies to everyone's claims, including
  maintainers'.
- Respect the legal boundaries. Requests to bundle game assets or redistribute
  another creator's mod will be declined, and pushing after a "no" is a conduct
  issue rather than a technical disagreement.

## Unacceptable behaviour

- Harassment, insults, or personal attacks
- Discrimination or demeaning comments about any personal characteristic
- Sexualised language or imagery
- Publishing others' private information without permission
- Sustained disruption of discussions
- Encouraging or facilitating piracy of the game or of others' mods

## Scope

Applies in all project spaces — issues, pull requests, discussions, commit
messages, code comments — and when representing the project elsewhere.

## Enforcement

Report concerns to the maintainers through a private GitHub security advisory or
by contacting a maintainer directly. Reports are handled discreetly.

Maintainers may remove, edit or reject contributions that violate this policy,
and may temporarily or permanently ban anyone whose behaviour they judge
inappropriate. Responses will be proportionate: most problems are best resolved
by a private word.

# Project rules

- Never invent map locations, locators, game codes, commands, or capabilities.
- Search provenance-backed registries before referencing game content.
- Validate before building; never manually edit generated output.
- Never expose secrets or touch original game files.
- Never redistribute game or third-party mod assets.
- Label unsupported and unverified features honestly.
- Prefer deterministic toolkit functions over free-form generation.

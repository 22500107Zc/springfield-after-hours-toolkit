# Roadmap and honest limitations

The MVP does not yet claim playable mission generation. Next milestones are:

1. Research, license-review, and pin an official Game.lua revision; implement an adapter against verified calls.
2. Expand registries only from traceable sources and user-supplied legal metadata.
3. Implement safe scaffolding, packaging, dialogue exporters, compatibility inspection, and asset copying.
4. Add optional Lucas Mod Launcher Lua definitions setup and a future pure3d-ts metadata boundary.
5. Add opt-in Anthropic assistance with schema parsing, proposed diffs, confirmation, and cost controls.
6. Define a permissioned plugin SDK; never auto-execute untrusted plugins.
